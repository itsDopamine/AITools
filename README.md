# AITools

个人 AI 工具与相关资源集合，用于集中管理 MCP、技能、规则及其他辅助项目。

## 目录结构

```
AITools/
├── mcp/          # MCP 服务相关
├── skills/       # Agent Skills
├── rules/        # Cursor / Agent 规则
└── other/        # 其他相关项目与工具
```

## 说明

- `mcp/`：存放 MCP（Model Context Protocol）相关服务，例如 interactive-feedback 等。
- `skills/`：存放可复用的 Agent Skill。
- `rules/`：存放 Cursor / Agent 规则配置。
- `other/`：存放其他独立项目或实验性工具（如 Understand-Anything）。

## 使用

本仓库主要用于本地整理与版本管理。各子目录下的项目可按其自身文档独立安装与运行。
