# 工作卡片模板

文件名建议：`works/<序号>-<短标题>.md`，例如 `works/03-template-library-v2.md`。

```markdown
# <工作项标题>

> **简历可用一句话：** <一句话成就，尽量含技术关键词与结果>

| 字段 | 内容 |
|------|------|
| 仓库 | `<repo-id>` |
| 时间 | `YYYY-MM` ~ `YYYY-MM` |
| 角色 | 主导 / 核心开发 / 参与 |
| 来源文档 | [链接或路径] |
| 关键 commits | `abc1234`, `def5678`（可多） |

## STAR

### Situation
<背景与约束：业务问题、技术债、协作环境。已脱敏。>

### Task
<你的目标与职责边界。>

### Action
- **<概括>：** <具体做法、技术选型、关键设计；接口只用模拟路径或关键字段>
- **<概括>：** <…>

### Result
- **<概括>：** <尽量量化；缺数时写 [待补充量化]>
- **<概括>：** <质量/稳定性/协作侧收益>

## 可粘贴简历分点（可选精炼）

- **<概括>：** <已脱敏、可直接进简历的表述>
- **<概括>：** <…>

## 来源追溯

- commits: …
- docs: …
- 更新记录: 见 `changelog/…`
```

## 聚类原则

- 同一需求/同一技术方案多次提交 → 一张卡
- 纯格式化、锁文件、无关 chore → 不单独建卡，可附录
- 无法归类 → `works/_unclassified.md`
